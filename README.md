# Студенттерді басқару жүйесі

## Жоба туралы
Бұл жоба PHP және MySQL қолданып әзірленетін толыққанды веб-қосымша болып табылады[cite: 1]. Жүйе оқу орнындағы студенттердің жеке мәліметтерін, топтарын және оларға қатысты ақпараттарды орталықтандырылған түрде тиімді басқаруға арналған.

## Негізгі мүмкіндіктері
- Пайдаланушыларды (әкімші/оқытушы) тіркеу және қауіпсіз кіру жүйесі[cite: 1]
- Студенттер туралы мәліметтерге толық CRUD (қосу, қарау, өңдеу, жою) операцияларын жасау[cite: 1]
- Студенттерді аты немесе тобы бойынша іздеу және сүзу[cite: 1]
- Серверлік валидация және қауіпсіздік шаралары[cite: 1]

## Қолданылатын технологиялар
- HTML5, CSS3, JavaScript[cite: 1]
- PHP (PDO)[cite: 1]
- MySQL дерекқоры[cite: 1]

## Негізгі беттер тізімі
1. **Басты бет** (`index.php`) — Жүйе туралы жалпы сипаттама.
2. **Кіру және Тіркелу беттері** (`login.php`, `register.php`) — Жүйеге кіруге және тіркелуге арналған формалар[cite: 1].
3. **Басқару панелі** (`dashboard.php`) — Студенттер тізімі көрсетілетін және басқарылатын негізгі қорғалған бет.

## Дерекқор құрылымы (ER-диаграмма)
Жоба үшін 3 негізгі кесте жобаланды[cite: 1]:
- `users` (Пайдаланушылар / Әкімшілік тіркелгілері)
- `students` (Студенттердің жеке мәліметтері)
- `groups` (Топтар тізімі)
