# Студенттердің үлгерімін есепке алу жүйесі

## Жоба туралы
Бұл жоба PHP және MySQL қолданып әзірленетін толыққанды веб-қосымша болып табылады. Жүйе оқу орнындағы студенттердің жеке мәліметтерін, топтарын және оларға қатысты ақпараттарды орталықтандырылған түрде тиімді басқаруға арналған.

## Негізгі мүмкіндіктері
- Оқытушыларды (әкімші/оқытушы) тіркеу және қауіпсіз кіру жүйесі
- Студенттер туралы мәліметтерге толық CRUD (қосу, қарау, өңдеу, жою) операцияларын жасау
- Студенттерді аты немесе тобы бойынша іздеу және сүзу
- Серверлік валидация және қауіпсіздік шаралары

## Қолданылатын технологиялар
- HTML5, CSS3, JavaScript
- PHP (PDO)
- MySQL дерекқоры

## Негізгі беттер тізімі
1. **Басты бет** (`index.php`) — Жүйе туралы жалпы сипаттама.
2. **Кіру және Тіркелу беттері** (`login.php`, `register.php`) — Жүйеге кіруге және тіркелуге арналған формалар.
3. **Басқару панелі** (`dashboard.php`) — Студенттер тізімі көрсетілетін және басқарылатын негізгі қорғалған бет.

## Дерекқор құрылымы (ER-диаграмма)
Жоба үшін 3 негізгі кесте жобаланды:
- `teachers` (Оқытушы / Әкімшілік тіркелгілері)
- `students` (Студенттердің жеке мәліметтері)
- `groups` (Топтар тізімі)
- `subjects`(Пәндер)
- `grades`(Студенттің бағалары)
