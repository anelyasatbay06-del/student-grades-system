 СТУДЕНТТЕРДІ ЕСЕПКЕ АЛУ ЖҮЙЕСІ

 1. Жобаның тақырыбы

Студенттерді есепке алу жүйесі — студенттер туралы ақпаратты сақтау, басқару және олардың оқу үлгерімін бақылауға арналған веб-қосымша.

 2. Жобаның мақсаты

Жобаның негізгі мақсаты — студенттердің жеке мәліметтерін, топтарын, пәндерін және бағаларын бір жүйеде сақтауға мүмкіндік беретін веб-қосымша әзірлеу.

Жүйе қажетті ақпаратты жылдам табуға, мәліметтерді жаңартуға және студенттердің оқу үлгерімін бақылауға көмектеседі.

 3. Жобаның негізгі мүмкіндіктері

* Студенттер туралы ақпаратты сақтау
* Жаңа студент қосу
* Студент мәліметтерін өзгерту және жою
* Студенттердің тізімін көру
* Оқу топтары туралы ақпаратты сақтау
* Пәндер тізімін жүргізу
* Студенттердің бағаларын енгізу және қарау
* Студенттерді аты-жөні бойынша іздеу
* Пайдаланушыны тіркеу және жүйеге кіру
* Мәліметтердің қауіпсіздігін қамтамасыз ету

 4. Жобаның негізгі беттері

4.1. Басты бет

Жүйенің атауы және негізгі бөлімдерге өту батырмалары орналасады.

4.2. Тіркелу және кіру беті

Пайдаланушы тіркеліп, логин мен құпиясөз арқылы жүйеге кіре алады.

4.3. Студенттер беті

Студенттердің тізімі мен жеке мәліметтері көрсетіледі. Жаңа студент қосуға, ақпаратты өзгертуге және жоюға болады.

4.4. Топтар беті

Студенттердің оқу топтары туралы ақпарат сақталады.

4.5. Пәндер беті

Оқу пәндерінің тізімі және пәндер туралы мәліметтер көрсетіледі.

4.6. Бағалар беті

Студенттердің пәндер бойынша алған бағалары көрсетіледі.

4.7. Іздеу беті

Қажетті студентті аты-жөні бойынша табуға мүмкіндік береді.

 5. Дерекқор құрылымы

Жобада MySQL дерекқоры қолданылады. Дерекқор бес негізгі кестеден тұрады.

Кесте атауы	Сипаттамасы
Students	Студенттердің жеке мәліметтері
Groups	Оқу топтары туралы ақпарат
Subjects	Пәндер туралы ақпарат
Grades	Студенттердің пәндер бойынша бағалары
Users	Жүйе пайдаланушылары туралы ақпарат

Кестелер арасындағы байланыстар:

* Бір топта бірнеше студент оқи алады.
* Бір студент бірнеше пән бойынша баға ала алады.
* Жүйе пайдаланушылары тіркеліп, жүйеге кіре алады.

 6. Қолданылатын технологиялар

* HTML — веб-беттің құрылымын жасау.
* CSS — веб-бетті безендіру.
* JavaScript — интерактивті мүмкіндіктер қосу.
* PHP — серверлік бөлімді әзірлеу.
* MySQL — мәліметтерді сақтау және басқару.
* GitHub — жоба файлдарын сақтау.
* Draw.io — ER-диаграмма құру.

 7. ER-диаграмма

ER-диаграмма жүйенің дерекқор кестелерін және олардың арасындағы байланыстарды көрсетеді.

Диаграммадағы негізгі кестелер:

1. Students
2. Groups
3. Subjects
4. Grades
5. Users

ER-диаграмманың мақсаты — дерекқор құрылымын алдын ала жоспарлау және кестелер арасындағы байланысты көрсету.

 8. Жобаны әзірлеу жоспары

1. Жоба тақырыбын таңдау және мақсатын анықтау.
2. Негізгі беттер мен функцияларды жоспарлау.
3. Дерекқор кестелерін жобалау.
4. ER-диаграмма құру.
5. GitHub репозиторийін ашу және README файлын толтыру.
6. Веб-интерфейсті әзірлеу.
7. PHP және MySQL арқылы жүйенің функцияларын іске асыру.
8. Жобаны тестілеу және қателерін түзету.

 9. Қорытынды

Студенттерді есепке алу жүйесі студенттердің мәліметтерін бір жерде сақтауға және басқаруға арналған.

Жобаны іске асыру арқылы студенттер, оқу топтары, пәндер және бағалар туралы ақпаратты жүйелі түрде жүргізуге болады.

Қазіргі кезеңде жобаның мақсаты, негізгі мүмкіндіктері, беттер тізімі және дерекқордың бастапқы құрылымы жоспарланды.
